## Abrir e publicar
- Abrir `index.html` no navegador para a versão portuguesa; `en/index.html` para inglês.
- Para publicar, enviar toda a pasta para alojamento estático com HTTPS (Netlify, Cloudflare Pages, GitHub Pages ou outro). Os links dos ficheiros são relativos.
- Depois de escolher o domínio, acrescentar às duas páginas `<link rel="canonical" href="https://...">`, `<link rel="alternate" hreflang="pt-PT" href="https://...">`, `<link rel="alternate" hreflang="en" href="https://.../en/">` e as etiquetas absolutas `og:url` e `og:image`. Depois, configurar um sitemap com os dois endereços e submeter ao Google Search Console e Bing Webmaster Tools.
- Confirmar com o atleta autorização para publicar as 3 fotografias; existem outras pessoas numa delas. Confirmar também os direitos de utilização e divulgação das imagens.
- Fornecer o e-mail oficial de representação e redes sociais para substituir a informação provisória na secção de parcerias. Não inventar contactos.
